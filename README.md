# estudioseijo.com · kit de arranque del desarrollo

Este kit prepara el repositorio para que Claude Code (u otro desarrollador) construya el sitio completo a partir de la
maqueta aprobada.

## Contenido
- `CLAUDE.md`: instrucciones del desarrollador especialista (papel, stack, funcionalidades, calidad, forma de trabajo).
- `referencia/maqueta/`: maqueta HTML funcional aprobada (ábrela con `index.html`).
- `referencia/marca/`: manual de marca y logotipos.
- `referencia/contenidos/`: ofertas, migración del blog y pendientes.
- Diseño editable de las páginas (lienzo en Claude): https://claude.ai/artifact/Wq4VDXbRGxSKLZYmtsNA4K

## Cómo arrancar
1. Crea un repositorio vacío en GitHub, por ejemplo `estudioseijo-web` (privado).
2. Descomprime este kit en la raíz del repositorio y haz el primer commit («Kit de arranque»).
3. Abre el repositorio con Claude Code.
4. Primer mensaje:
   > Lee CLAUDE.md y todo lo que hay en /referencia. Antes de escribir código, propón la estructura del proyecto,
   > las dependencias y el plan detallado de la fase 1, y dime qué datos de referencia/contenidos/pendientes.md
   > necesitas primero.
5. Ve aprobando fase a fase. Cada fase termina con una *pull request* que puedes revisar antes de unirla.

## Decisiones a cerrar antes de la fase 4 (reservas)
- Hosting definitivo (necesario para el adaptador de servidor de Astro).
- Cuenta de Google: Workspace (más sencillo) o Gmail personal (OAuth).
- Horario de reuniones, duración y festivos.
